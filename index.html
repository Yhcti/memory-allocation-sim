OS Final Project Topic E1
Memory Allocation

First Fit vs Best Fit

A tiny simulator that shows how an operating system picks a free block of memory, and how much space each choice wastes.

01

The idea

When a program (process) needs memory, the operating system must choose which free block of memory to give it. Different choices waste different amounts of space.

  • First Fit: use the first block that is big enough.
  • Best Fit: use the smallest block that is big enough.

Key term

Each block holds at most one process (fixed partitions). The space left over inside a used block is called internal fragmentation:

Leftover = Block size − Process size
